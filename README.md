# 🧠 Mind Hacker: AI Puzzle Arena

## 🚀 Overview

**Mind Hacker: AI Puzzle Arena** is an AI-inspired web game where the player uses mathematical problem-solving skills to defeat enemies.

Instead of traditional weapons, **the player’s intelligence becomes the weapon**, creating a unique fusion of:

* 🧠 Artificial Intelligence concepts
* 🔢 Mathematics
* ⚔️ Combat gameplay

---

## 🎮 Features

* ⚔️ **Math-Based Combat System** – Solve problems to attack enemies
* 🤖 **AI Difficulty Scaling** – Game adapts based on player performance
* 🔥 **Combo Attack System** – Consecutive correct answers increase damage
* ⏱️ **Timer-Based Challenges** – Adds pressure and excitement
* 💥 **Boss Mode** – Increased difficulty after high score
* 🎨 **Neon UI Design** – Attractive cyberpunk-style interface
* 🎵 **Sound Effects** – Interactive gameplay feedback

---

## 🧠 How It Works

1. Player enters the AI battlefield
2. A math question appears
3. Player submits answer
4. * ✅ Correct → Attack enemy
   * ❌ Wrong → Player takes damage
5. AI adjusts difficulty dynamically

---

## 🚀 Deployment

### GitHub

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/yourusername/mind-hacker-game.git
git push -u origin main
```

### Netlify

1. Go to Netlify
2. Click "Add new site" → Import from GitHub
3. Select repository
4. Deploy
